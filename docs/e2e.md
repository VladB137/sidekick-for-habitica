# What the e2e run checks

`tests/e2e.cjs` drives the built site in Chromium against `tools/mock-server.mjs`, a local stand-in for habitica.com built on Habitica’s own code and answering in the live server’s shapes. It runs the parts in `tests/e2e/` in order on one page, one file per screen or area (`login`, `crits`, `tasks`, `history`, `suggestions`, `day`, `offline`, `screens`, `stable`, `followups`, `classes`, `drops`, `repeats`, `android`, `relaxed`, `demo`), each starting where the one before it left off, then the Stable’s development pages (`tests/playground-e2e.cjs`, `tests/creatures-e2e.cjs`, `tests/scenes-e2e.cjs`). It prints every check as it goes and how many failed; `grep -c ^PASS` on its output is the count.
